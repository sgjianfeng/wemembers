# Meow BBQ：模版 / 券产品 / 活动 怎么理解、怎么用

> 生产只保留 **Uncle Meow / meow-bbq** 作为真实企业账户。  
> 结构：**模版 → 券产品 → 活动勾选产品 → 门店参与活动**。

---

## 一、四层概念（别混）

```
① 模版（默认图纸 / 可拷贝）
      ↓ 底栏「券产品」创建并上架
② 券产品（可售 SKU：激活/下架、购券链接）
      ↓ 活动勾选产品
③ 活动（门店选择参与；节日主题也可）
      ↓
④ 顾客券 / 入箱票
```

| 名称 | 是什么 | 谁创建 | 例子 |
|------|--------|------|------|
| **模版** | 规则图纸（折扣、扣点、档位默认值） | 平台 | 自用代金、独享 15% |
| **活动** | 某店/某企业正在卖的一条产品线 | 企业（或开店包自动建） | 原价无门槛代金、入箱大奖 |
| **券** | 顾客买到的一张余额/资格 | 顾客购买后系统生成 | 手机里 S$50 余额 |
| **入箱票** | 只投抽奖箱的纸，**不能当饭钱** | 店员打印发给顾客 | 纸票进箱子 |

**活动模版 vs 代金/抽奖模版？**  
- 代金、抽奖都是 **活动的一种**（`voucher_sale` / `lucky_draw_v2`）。  
- 不需要再单独搞一层「活动模版」；**默认活动 = 用模版规则创建好的 3 条 Campaign**。  
- 以后若要改扣点/门槛，可「拷贝模版 → 再开新活动」，不必天天改模版。

## 三、钱与赠送

| 账户 | 用途 |
|------|------|
| **赠送额度 gift**（默认每店 S$100，公司账户汇总） | 优先抵 **平台 2% 服务费**；**不能**当真金乱注大奖池 |
| **自充 balance** | 够付「小奖 3% + 大奖 10%」时，才真金进池、小奖进顾客余额 |
| 顾客 PayNow | 付 50/100 买 B 活动 → 系统按 15% 拆分 |

## 四、日常怎么用（店员话术）

### 场景 1：只卖预付代金（A1 / A2）

1. 顾客扫 **A1 或 A2** 二维码（或店员柜台现金发券）。  
2. 网上 PayNow / 柜台收现。  
3. 顾客手机有余额；核销时扫顾客券码，按面值抵扣。  
4. **A2**：账单金额要 ≥ 券面×10（核销时系统会查 `billCents`）。

### 场景 2：结账劝抽奖（B，主推）

1. 收银做完主单后问：**要不要参加大奖抽奖？**  
2. 同意 → 扫 **B 活动码**，选 **50 或 100**，PayNow。  
3. 收银机再记一笔抽奖收款（与系统并行对账）。  
4. 系统：小奖 + 池进度进手机。  
5. 店员从 **入箱票批次** 取一张对应 50/100 的纸票给顾客，**投入店内抽奖箱**（仪式感）。  
6. 纸票 **不能当饭钱**；以后开箱/表演用。

### 场景 3：顾客自己在桌上扫 B

与场景 2 同一条活动；只是没有店员递纸时，可后补打票或只看手机。

## 五、企业后台点哪里（别绕晕）

| 你想做的事 | 去哪 |
|------------|------|
| 看/管默认三条活动 | **活动** |
| 新建一条活动（少用） | **活动 → 新建** → 选自用 → 选模版 |
| 改自己的折扣/扣点图纸 | **功能仓 → 我的模版**（拷贝后改） |
| 打印入箱票 | **功能仓 → 入箱票印刷**（独立入口，不混在消费纸类型里），关联 B 活动 |
| 打印自用/抽奖消费纸 | **功能仓 → 实体印刷**，选活动与线上产品（类型随产品自动对应） |
| 柜台现金发自用券 | **功能仓 → 现金发券** 或 实体售出 |
| 核销 | **核销** 扫顾客券 |
| 看赠送/自充 | **账户 / Tokens** |
| 门店是否在卖 | 活动详情 **门店选用** 或 门店页开关 |

**默认活动已经创建好** → 日常 **不用每天「创建活动」**，只需：

1. 确认三条在「进行中」  
2. 门店已启用  
3. 入箱票有库存可打

## 六、和「测试垃圾活动」的关系

生产清理后 Meow 只保留上面 **3 条默认**。  
旧的 S$2 验账、三档 Test、旧独享等应已删除或归档，避免店员扫到错链。

---

## 七、一句话

> **模版是图纸；活动是货架上的货；券是顾客口袋；入箱票是箱子里的仪式纸。**  
> Meow 货架上默认就放 A1、A2、B 三样，长期卖；结账主推 B 扫码 + 投箱。
