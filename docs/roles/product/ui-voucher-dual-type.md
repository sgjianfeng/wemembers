# UI 规格：自用券 / 分发券

> 配套决策 D-P1-4 / D-P1-5 · 目标：**简单明了、美观大方**  
> 受众：门店店员（吵、急、单手）+ 企业老板（对账、怕误解）

---

## 1. 设计意图

| 项 | 决定 |
|----|------|
| **谁** | 店员在柜台核销；老板在后台看「钱在哪」 |
| **动词** | 选对类型创建 → 扫一码核销 → 一眼懂账 |
| **感觉** | **柜台工具感**：冷静、留白够、数字大、少字；像精致的收银条，不是报表丛林 |
| **签名元素** | **类型色条标签**（自用=石板蓝 / 分发=琥珀橙）贯穿创建、券面、核销、报表 |

### 拒绝的默认

| 默认 | 我们改成 |
|------|----------|
| 三个以上 Tab 核销 | **一个扫码入口**，类型由码决定 |
| 灰字长说明堆在标题下 | **一行对比 + 图标**，详情折叠 |
| 一个大「余额」混所有钱 | **自用 / 分发分区**，永不混加 |
| 成功只 toast「成功」 | **成功卡带类型结果**（入账 / 不入账） |

## 2. 视觉 token（对齐现有 WeMembers）

沿用品牌主色 `#1A6EFF`，补充类型语义（勿再引入第三套主色体系）：

| Token | 用途 | 建议 |
|-------|------|------|
| `--voucher-self` | 自用 | 石板蓝 `#334155` 字 + 浅蓝底 `#F1F5F9` / 左边条 `#64748B` |
| `--voucher-dist` | 分发 | 琥珀 `#B45309` 字 + 浅橙底 `#FFF7ED` / 左边条 `#F59E0B` |
| `--surface` | 卡片 | 白 + 极淡边 `border-slate-100`，圆角 `rounded-2xl` |
| `--focus` | 主按钮 | 现有 pill `rounded-full` + `#1A6EFF` |
| 数字 | 金额 | `tabular-nums`，主数字 28–32px semibold |

**密度**：手机主路径 padding 卡片内 16px，区块间距 16–20px；核销成功数字区再加大。

**深度**：浅边框 + 轻阴影一层即可，不叠重阴影。

## 3. 关键页面线框（文字线框）

### 3.1 创建代金 · 类型选择（第一步，全屏焦点）

```
┌─────────────────────────────┐
│  创建代金券                    │
│  先选类型（之后不能改）        │
│                             │
│  ┌─────────────────────┐   │
│  │ 🟦 自用券            │   │  ← 大卡片，可点选
│  │ 集团门店可共用        │   │
│  │ 售出即本店收款 · 无佣金 │   │
│  │ 平台不托管、不提现    │   │
│  └─────────────────────┘   │
│  ┌─────────────────────┐   │
│  │ 🟧 分发券            │   │
│  │ 可分享 · 可活动/抽奖  │   │
│  │ 平台托管 · 核销入账   │   │
│  └─────────────────────┘   │
│                             │
│  [ 下一步 ]                  │
└─────────────────────────────┘
```

- **一个焦点**：两张二选一卡片，选中态左边条 + 细描边品牌色。  
- 下方 **不要** 同时展开两套长表单。

### 3.2 创建 · 自用（示例字段）

```
类型条：自用券
适用：○ 全部门店  ·  ○ 指定门店
面额：S$ __
售出方式：现金（默认） / 其他店收
[ 创建 ]
```

### 3.3 创建 · 分发

```
类型条：分发券
活动名 / 档位或折扣 / 抽奖开关
支付：平台 Checkout
[ 创建并生成链接 ]
```

### 3.4 核销台（统一）

```
┌─────────────────────────────┐
│  扫码核销 · Meow Vivo       │
│  [ 📷扫码 ]                 │  ← 主 CTA，大
│  或输入短码 ________  查询   │
│                             │
│  ┌─ 查到 ───────────────┐  │
│  │ 🟦 自用券              │  │
│  │ 面额 S$10  余额 S$10   │  │
│  │ 顾客 · 门店范围集团    │  │
│  │                      │  │
│  │ 本次  [ 10.00 ]      │  │
│  │ [ 确认核销 ]           │  │
│  │ 核销后不重复入账       │  │  ← 自用提示
│  └──────────────────────┘  │
└─────────────────────────────┘
```

分发查到时：

```
│  🟧 分发券 · 核销入账 T+1    │
│  …                          │
│  提示：成功后收入进「冻结」   │
```

### 3.5 核销成功

| 自用 | 分发 |
|------|------|
| 大勾 + **已核销** | 大勾 + **核销成功** |
| 副文：本店记录已记，无二次入账 | 副文：本店实收 S$x · 已入冻结 |
| 次要：继续扫下一张 | 次要：去账户中心 |

### 3.6 账户 / 经营（老板）

```
┌ 分发券结算 ────────────────┐
│ 可用 S$x   冻结 S$y        │
│ [检查状态] [提现]           │
└────────────────────────────┘

┌ 自用券 ────────────────────┐
│ 今日售出（已收款）S$a       │
│ 待核销权益           S$b    │  ← 负债，灰色说明
│ 分店核销  今日 n 笔 →      │
└────────────────────────────┘
```

**禁止**：把 a+b+x 加总成一个「总余额」。

## 5. 文案字典（中）

| key 场景 | 文案 |
|----------|------|
| 类型自用 | 自用券 |
| 类型分发 | 分发券 |
| 自用一行 | 集团门店可共用 · 售出即收款 · 无佣金 |
| 分发一行 | 可分享分发 · 平台托管 · 核销后入账 |
| 自用核销成功 | 已核销 · 已记本店 · 不再入账 |
| 分发核销成功 | 核销成功 · 收入已入冻结（T+1 可提） |
| 待核销说明 | 顾客尚未消费的权益，不是平台欠款 |

## 6. 状态与错误

| 状态 | 表现 |
|------|------|
| 自用 · 非本集团店 | 红字：仅限集团门店使用 |
| 分发 · 未入网 | 沿用现网文案 |
| 余额不足 | 温和错误，保留已查信息 |
| 扫码中 | 全屏取景，成功自动关 |

---

## 7. 验收（设计）

- [ ] 店员不经培训能说出两张创建卡片的区别  
- [ ] 核销不依赖「先选自用/分发 Tab」  
- [ ] 老板不会把「待核销」当成「可提现」  
- [ ] 手机 390 宽一屏主路径无横向滚动、主按钮 ≥ 44pt 高
