# UI 规格：独享券 / 共赢券（抽奖）

> 配套 D-P1-6 / D-P1-7 · 与 `ui-voucher-dual-type.md`（自用/分发）**同一套信息架构**  
> 目标：简单明了、美观大方；店员不背两套账

---

## 1. 设计意图

| 项 | 决定 |
|----|------|
| **谁** | 店员发券/核销；老板看「现金独享」vs「平台共赢」 |
| **动词** | 选独享或共赢 → 发/卖 → 扫码核 → 懂钱与奖 |
| **感觉** | 与代金柜台同温：冷静、大数字、pill 按钮；抽奖只多 **奖** 的轻量兴奋（图标/一点琥珀），不抢资金信息 |
| **签名** | 资金标签沿用石板蓝（先收款）/ 琥珀橙（托管结算）；抽奖再叠小角标「抽奖」或 🎰 |

### 统一心智（挂培训墙）

```
         先收款（店）              平台托管
无奖      自用券                   分发券
有奖      独享券                   共赢券
```

## 2. 视觉

| 类型 | 左边条 / 标签底 | 字色 | 说明 |
|------|-----------------|------|------|
| 独享（先收款） | `#64748B` / `#F1F5F9` | slate-700 | 与 **自用** 同色系 |
| 共赢（托管） | `#F59E0B` / `#FFF7ED` | amber-800 | 与 **分发** 同色系 |
| 抽奖角标 | 小圆 pill `bg-violet-50 text-violet-700` | 仅表示有奖，不改资金色 |

**禁止** 独享用绿、共赢用红等第三套主色，避免再学一套。

---

## 3. 创建流程

### 3.1 第一步：品类（若入口是「创建活动」总入口）

```
创建什么？
  [ 代金券 ]   [ 抽奖券 ]
```

### 3.2 第二步：资金类型（与代金对称）

**抽奖 · 独享**

```
┌ 独享券 ─────────────────────┐
│ 集团门店可核                  │
│ 先收钱（现金/店收）再核销余额   │
│ 无卖券佣金 · 平台不托管不提现   │
│ 即时小奖店内承担 · 默认无平台大奖池 │
└──────────────────────────────┘
```

**抽奖 · 共赢**

```
┌ 共赢券 ─────────────────────┐
│ 可分享 · 入网可互核            │
│ 顾客平台支付 · 核销后入账 T+1   │
│ 可佣金 · 核销进奖池做大延迟奖   │
└──────────────────────────────┘
```

### 3.3 第三步：配置

| 独享 | 共赢 |
|------|------|
| 档位 50/100/200 或自定义 | 同左（现网三档） |
| 即时奖表（店兑） | 即时奖 + 延迟奖品/目标 |
| 适用门店：全集团 / 指定 | 伙伴、slug、分享 |
| **无** Stripe 必填 | 强调支付链接 |

---

## 4. 柜台发独享（现金）

与 `/business/issue-self` **同一交互模式**（可共用页，按活动 play=draw）：

1. 勾选已收款  
2. 选档位金额  
3. 发 **6 位短码**（大字）  
4. 可选：当场抽即时小奖 → 屏幕展示奖品 + 记日志  
5. 顾客凭短码/余额核销消费  

文案：

> 钱已在店；核销只扣余额、记门店；中奖由本店兑付。

---

## 5. 核销台（统一扫码）

查到后主标签 **二选一资金色** + 小角标抽奖：

```
[ 独享券 ] [抽奖]
余额 S$50
提示：售出已收款 · 核销不入平台账户
[ 确认核销 ]
```

```
[ 共赢券 ] [抽奖]
余额 S$50
提示：核销后约 20% 进奖池，其余入冻结 T+1
[ 确认核销 ]
```

成功：

| 独享 | 共赢 |
|------|------|
| 已核销 · 已记本店 · 无二次入账 | 核销成功 · 实收 S$x · 已入冻结 |
| 若有待兑即时奖，次要提示「中奖待兑」 | 可链奖池进度 |

---

## 6. 老板账户 / 经营

```
┌ 共赢 · 平台结算 ──────────────┐
│ 可用 / 冻结 / 提现 / 检查状态   │
└────────────────────────────────┘

┌ 独享 · 店内已收款 ────────────┐
│ 今日售出 S$a                   │
│ 待核销余额 S$b（负债）          │
│ 今日中奖 n 笔 · 待兑            │
│ 分店核销 →                     │
└────────────────────────────────┘
```

**永不** 把 a 与可用余额加总。

## 7. 消费者

| 独享 | 共赢 |
|------|------|
| 短码 / 我的余额 · 标签独享 | `/voucher/{slug}` 购券抽奖 |
| 可看即时奖记录 | 即时奖 + 大奖池倒计时 |
| 到店核销消费金 | 全网/入网核销 |

---

## 8. 状态与错误

| 情况 | 表现 |
|------|------|
| 独享在非集团店核 | 仅限本企业门店 |
| 共赢未入网 | 现网文案 |
| 独享无冻结却提示提现 | **禁止** 出现提现 CTA |
| 大奖池在独享活动 | UI 隐藏平台池；若配置本地奖则标明「本店奖」 |

---

## 10. 验收（设计 + 试点）

- [ ] 店员能用一句话区分独享 vs 共赢  
- [ ] 核销不选手动「要不要进奖池」  
- [ ] 老板不把独享售出当成可提现  
- [ ] 独享即时奖有记录、有「店兑」预期  
- [ ] 共赢仍可演示 PayNow + 奖池
